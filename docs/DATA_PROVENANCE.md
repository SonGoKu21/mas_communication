# Benchmark evidence provenance

The position-extension donor manifests preserve table content projected from archived WebArena Admin benchmark runs. Their `source_file`, source digest, projection digest and entry-level provenance bind each carrier to its recorded input. Contact-like strings inside a benchmark table are task evidence, rather than project-author contact information. They are retained to preserve the input and evaluation semantics; the release does not infer that a string is synthetic solely from its appearance.

Source manifests and analysis inputs must be distinguished from author metadata, deployment directories and credentials. Candidate-level taxonomy annotation evidence is documented separately in [taxonomy construction materials](ANNOTATION_MATERIALS.md). Scheduled execution counts and unknown outcomes are documented in [the study inventory](STUDY_INVENTORY.csv).
